# 🍕 Sistema de Gestão para Pizzaria

Sistema web de gestão de pedidos e cadastro de produtos desenvolvido como
projeto em grupo do curso Técnico em Desenvolvimento de Sistemas (SENAI).

## Sobre o projeto

Aplicação que simula o fluxo operacional de uma pizzaria: cadastro de itens
do cardápio, registro de pedidos e controle de acesso aos dados. O foco do
projeto foi aplicar, na prática, modelagem de banco de dados relacional e
operações CRUD completas com validação no lado do cliente.

## Funcionalidades

- Cadastro, listagem, edição e exclusão de produtos (CRUD completo)
- Validação de formulários no lado do cliente
- Tratamento de erros de entrada
- Modelagem relacional com definição de tabelas, chaves primárias e
  relacionamentos
- Controle de permissões de acesso ao banco de dados

## Tecnologias

- **JavaScript** — lógica de negócio e manipulação do DOM
- **MySQL** — modelagem e persistência dos dados
- **HTML5** e **CSS3** — estrutura e estilização da interface
- **Git** — versionamento
